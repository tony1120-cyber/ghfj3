# DARK CORRIDOR

브라우저에서 실행하는 3D 공포 게임 프로토타입입니다.

## 실행 방법
- `index.html`을 웹 서버로 실행하세요. ES module과 Three.js CDN을 사용하므로 파일을 직접 여는 것보다 GitHub Pages나 VS Code Live Server를 권장합니다.
- GitHub Pages: 저장소 Settings → Pages → 배포 소스를 `main` 브랜치와 `/ (root)`로 선택합니다.

## 조작
- WASD: 이동
- 마우스: 시점 회전 (게임 화면 클릭)
- F: 손전등 켜기/끄기
- E: 출구와 상호작용
- 열쇠 3개를 모은 뒤 출구에서 E를 누르세요.

Three.js는 CDN에서 불러옵니다. 게임을 실행하려면 인터넷 연결이 필요합니다.
